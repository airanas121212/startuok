# Startuok GitHub Pages

Vieno puslapio lietuviška svetainė projektui **Startuok**.

## Paleidimas per GitHub Pages

1. Sukurkite naują GitHub repozitoriją, pvz. `startuok-online`.
2. Įkelkite visus šio aplanko failus į repozitorijos šaknį.
3. GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Pasirinkite `main` šaką ir `/ (root)`, tada **Save**.
5. GitHub Pages skiltyje įrašykite custom domain `startuok.online` ir įjunkite **Enforce HTTPS**, kai DNS bus aktyvus.

## Kas jau sutvarkyta

- Hero tekstas ir CTA supaprastinti.
- Maketai sąžiningai pažymėti kaip koncepcinės kryptys, ne klientų darbai.
- Pridėta skiltis, paaiškinanti naujo prekės ženklo darbo standartą.
- Sutvarkyta kainodaros logika ir kontaktų forma su kopijavimo atsarga.
- Pridėta privatumo informacija, socialinio dalinimosi paveikslas ir optimizuoti vaizdai.
- Pašalintas išorinis Google Fonts užkrovimas.

## Prieš viešą paleidimą

- Patvirtinkite kainas, terminus ir tikslią paslaugų apimtį.
- Patvirtinkite, kad veikia `labas@startuok.online`.
- Kai atsiras realių darbų, pakeiskite koncepcines kryptis tikrais projektais ir aiškiai aprašytais rezultatais.
- Kai norėsite tikro formos pateikimo svetainėje, prijunkite Formspree, Basin ar nuosavą serverio endpointą ir atnaujinkite privatumo informaciją.
- Analitiką diekite tik kartu su tinkamu privatumo ir sutikimų sprendimu.
